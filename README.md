# Conecta Campus

Site estático sobre os espaços e serviços do campus, desenvolvido em grupo para o
Checkpoint 2 (HTML + CSS + Git/GitHub).

## Páginas

- `index.html` - apresentação do projeto e locais em destaque;
- `locais.html` - lista dos locais e serviços do campus;
- `detalhes.html` - informações completas de um local;
- `integrantes.html` - integrantes do grupo.

## Estrutura

- `css/style.css` - folha de estilos única, compartilhada pelas quatro páginas;
- `img/` - imagens usadas nas páginas, com nomes em letras minúsculas.

## Tecnologias

HTML5 e CSS3. O projeto não usa JavaScript, frameworks nem bibliotecas externas.
